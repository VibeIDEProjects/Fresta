# `scripts/bin/` — dev-хелперы для maintainer'а

Переиспользуемые Python-скрипты, которые помогают в release-процессе и
диагностике. **Не** runtime-утилиты (те — в `scripts/{check,deploy,harvest,recon,relay}/`).
**Не** одноразовые фикстуры (те класть в `C:\Users\Public\` или `/tmp/`).

## Что тут лежит

| Скрипт                  | Назначение                                                                 |
|-------------------------|----------------------------------------------------------------------------|
| `bump_version.py`       | Поднять версию в `pyproject.toml` + `fresta/__init__.py` + `CHANGELOG.md`. |
| `check_pep585.py`       | Проверить, что в runtime-коде нет PEP 585 generic (`list[...]`, `dict[...]`) — иначе падает на Python 3.8. |
| `check_pyc_locks.py`    | Найти забытые `__pycache__/` (если `__pycache__/` не в .gitignore).         |

## Когда добавлять новый

Сюда стоит положить скрипт, если:
- его пришлось писать **больше одного раза** при разных релизах/диагностике;
- он не зависит от секретов/внешних сервисов;
- результат его работы — **изменение в репо** (bump версии, фикс) или **отчёт** (check).

Не стоит класть сюда одноразовые вещи вроде «один раз скопировать configs с сервера» —
это пусть живёт в `C:\Users\Public\` или `/tmp/`.

## Соглашения

- Кодировка файлов — UTF-8 (кириллица в комментариях/строках — это норма).
- Запускаются из **корня репо** (`python3 scripts/bin/<name>.py`).
- Идемпотентны: повторный запуск после успеха — `OK: already at <state>, skip`.
- Только stdlib (как и весь рантайм fresta).
